# Privacy Policy: Rover Explorer

Last updated: 11 October 2026

Rover Explorer is a file manager made by Dhiva Labs. This policy covers the
app on every platform it ships on (Windows, including the Microsoft Store
build, and Linux).

## Summary

Rover Explorer does not collect, send or sell any data. It has no accounts,
analytics, telemetry, advertising or crash reporting, and it makes no network
connections. Nothing about you or your files is sent to Dhiva Labs or anyone
else.

## Data stored on your device

- **Search index.** To make search instant, the app keeps a list of the file
  and folder names and paths under your home folder in a file called
  `rover_index.txt`. It holds names and paths only, never file contents. It is
  stored in the app's application-support folder (on Windows,
  `%APPDATA%\Dhiva Labs\Rover Explorer`, or the app's private package storage
  when installed from the Microsoft Store). Delete that file to remove the
  index; it is rebuilt on the next launch.
- **Sound file.** The companion's bark is copied to your temporary folder as
  `rover_woof.wav` so the system sound player can play it.

Folder Options choices are kept in memory only and reset when the app closes.

## Your files

Opening, copying, moving, renaming and deleting files happens only on your
device and only when you ask for it. Opening a file hands it to the program
your system uses for that file type.

## Network access

None. The Microsoft Store package declares no network capability.

## Children

The app does not collect personal information from anyone, including
children.

## Changes

If this policy changes, the new version will be published in this file, in
the app's public repository: <https://github.com/Dhiva-Labs/rover_explorer>.
